# TPI Fotaza 2

Trabajo Practico Integrador de la Materia Programacion Web II 

## Instalación

Sigue estos pasos para preparar el entorno:

1. **Clonar el repositorio:**
   `git clone <https://github.com/Emi-legui/Tpi-Fotaza2.git>`

2. **Instalar dependencias:**
   `npm install`

3. **Configuracion:**
   Crea un archivo `.env` en la raiz basandote en el archivo `.env.example` y completa tus datos de conexion a la base de datos.

4. **Inicializar la base de datos:**
   `npm run db:init`

## Ejecucion

Para iniciar el servidor en modo desarrollo, ejecuta:

`npm start`
